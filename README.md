# astrbot_plugin_bilibili_analysis

B 站视频链接解析插件，移植自 [koishi-plugin-bilibili-videolink-analysis](https://www.npmjs.com/package/koishi-plugin-bilibili-videolink-analysis)。

> **平台支持：仅 QQ**（AstrBot 的 `aiocqhttp` 适配器，OneBot v11 协议，NapCat / Lagrange 等均可）

## 功能

聊天中出现以下任意一种 B 站内容时，机器人自动回复视频信息（标题 / UP 主 / 数据 / 封面），并按模板可选下载发送视频：

| 来源 | 说明 | 示例 |
|---|---|---|
| 完整链接 | B 站视频页 URL，支持 `?p=N` 分 P 与 `www.` / `m.` 域名 | `https://www.bilibili.com/video/BV1xx411c7mD?p=2` |
| 短链 | b23.tv 及 bili22 / bili23 / bili33 / bili2233.cn 短域名 | `https://b23.tv/xxxxx` |
| 仅 BV/AV 号 | 消息中独立出现的视频号（不属于任何链接） | `这个视频不错 BV1xx411c7mD` |
| 卡片 | QQ 分享的 B 站 JSON 小程序卡片 | 手机 QQ 分享卡片 |

四种来源可分别开关；同一条消息出现多个视频时最多解析前 3 个（可配）。

其它能力：

- **消息模板**：通用模板与卡片模板独立配置，emoji 风格默认模板，`${~~~}` 拆分多条消息，`${视频}` 占位符控制是否下载并发送视频
- **合并转发**：图文与视频节点合并为一条转发消息，发送失败自动降级逐条发送
- **等待提示**：解析前发送提示语，完成后自动撤回
- **频率限制**：单用户 30 秒内最多 5 个视频；同一会话内重复链接最小间隔去重（默认 180 秒）
- **双数据源容灾**：视频信息优先走原版解析 API（信息与直链一次返回）；其超时或失败时自动切换 B 站官方 API（含真实分 P 列表），视频直链经官方 `playurl`（wbi 签名，无登录最高 480P）获取
- **请求容灾**：每个 API 请求均支持直连 / Apifox 代理 / 并行竞速三种模式

## 安装

1. 将本插件安装到 AstrBot（插件市场搜索、WebUI 上传，或手动放入 `data/plugins/astrbot_plugin_bilibili_analysis/`）
2. 无需额外依赖（仅使用 AstrBot 自带的 `aiohttp`）
3. **必须配置 `callback_api_base`**（发送视频的前提）：在 AstrBot 配置中把 `callback_api_base` 设为**协议端可访问**的 AstrBot 地址（如 `https://astrbot.example.com`）。发送视频时文件经 AstrBot 文件服务转成回调 URL 交给协议端下载——未配置或协议端（NapCat 等）访问不到该地址时，合并转发内的视频会发送失败（自动降级为仅发图文）；本地/同机部署同样建议配置以保证稳定
4. 在 WebUI 插件管理中启用，按需在配置页调整

## 配置项说明

所有配置在 WebUI 插件配置页修改，保存后重载插件生效。

### 解析

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 开启 B 站链接解析 | 开 | 总开关。关闭后不再响应任何 B 站内容 |
| 允许触发的消息来源 | 全部四种 | 多选：卡片 / 完整链接 / 仅BV·AV号 / 短链。仅勾选的来源会触发解析，例如只留"卡片"则文字链接不再解析 |
| 单条消息最多解析链接数 | 3 | 一条消息含多个视频时，只解析前 N 个，防止刷屏；不小于 1 |
| 解析前的等待提示语 | 空 | 解析开始前先发送这句话，解析完成后自动撤回；留空不发送。适合解析耗时较长的场景给用户反馈 |

### 消息模板

模板中可用的占位符：

| 占位符 | 内容 |
|---|---|
| `${标题}` `${UP主}` | 视频标题、UP 主昵称 |
| `${简介}` | 视频简介，超出长度上限时截断加 `...` |
| `${点赞}` `${投币}` `${收藏}` `${转发}` `${观看}` `${弹幕}` | 六项互动/播放数据 |
| `${播放链接}` | B 站网页播放器链接（可直接在线播放） |
| `${视频地址}` | 普通视频页链接，按下方"视频号偏好"输出 BV 或 AV 地址 |
| `${封面}` | 视频封面图 |
| `${视频}` | 下载并发送视频文件本身；**删除此占位符则完全不下载视频** |
| `${tab}` | 制表符，用于对齐 |
| `${~~~}` | 消息拆分符：将其前后的内容拆成两条独立消息发送 |

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 通用消息模板 | 见下方默认模板 | 用于完整链接 / 短链 / 仅BV·AV号 三种来源 |
| 卡片消息模板 | 见下方默认模板 | 用于 QQ 分享卡片来源，默认与通用模板同布局；留空时回落使用通用模板 |
| 简介最大字符数 | 50 | `${简介}` 超出此长度时截断 |
| 大数字缩写为万、亿 | 开 | 关闭后 `${点赞}` 等显示完整数字 |
| 视频号偏好 | bv | `${视频地址}` 使用 BV 号还是 AV 号 |

两种默认模板（同一布局）：

```
 ${标题}
👤 ${UP主}

👍 ${点赞} ${tab} 🪙 ${投币} ${tab} ⭐ ${收藏}
👀 ${观看} ${tab} 💬 ${弹幕} ${tab} 🔁 ${转发}

 ${简介}

🔗 ${视频地址}

▶️ ${播放链接}

${封面}
${视频}
```

其中 `${视频地址}` 为普通视频页跳转地址（如 `https://www.bilibili.com/video/BV1KKhpziEEn`，按"视频号偏好"输出 BV 或 AV），`${播放链接}` 为 B 站网页播放器。

### 视频与转发

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 下载并发送视频 | 开 | 视频发送总开关。开启时模板含 `${视频}` 才会下载并发送视频；**关闭后所有视频均不下载不发送，仅发送消息模板的文字与封面，模板中的 `${视频}` 占位符自动忽略** |
| 视频最大下载大小 | 50 MB | 超过此大小放弃下载仅发图文。取值 0~200，0 表示不限制。无 Content-Length 的大文件也会在流式下载中超限中止 |
| 开启合并转发 | 开 | 图文与视频节点合并为一条 QQ 合并转发消息（视频独占转发节点）；关闭后逐条发送。协议端不支持转发时自动降级逐条。**合并转发内的视频依赖 `callback_api_base` 文件服务**（见安装一节） |

### 频率限制

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 同一链接最小处理间隔 | 180 秒 | 同一会话中，同一视频（含同分 P）在此间隔内重复出现只解析第一次；不小于 1 |
| 单用户解析频率限制 | 开 | 30 秒窗口内单用户最多解析 5 个视频，超限后暂停处理该用户的消息并清空其待处理任务 |

### 网络与调试

| 配置项 | 默认值 | 说明 |
|---|---|---|
| API 请求模式 | parallel | 对所有 API 请求生效。direct 直连；proxy 经 Apifox 代理访问（适合直连被墙/被风控的网络）；parallel 同时发起直连与代理，取最先成功的结果 |
| 请求 B 站 API 的 User-Agent | Chrome UA | 所有对 B 站及解析 API 的请求头 |
| 解析失败时提示 | 关 | 开启后无法解析时回复提示（如视频不存在或仅大会员可见） |
| 开启调试日志 | 关 | 输出插件运行细节日志，排查问题时开启 |
| 输出完整消息结构日志 | 关 | 输出渲染后消息的组件结构，仅调试用 |

## 已知限制

- 不支持大会员专属 / 付费 / 充电专属视频
- 等待提示撤回、合并转发仅 QQ 平台生效
- 发送视频依赖 AstrBot 的 `callback_api_base` 文件服务配置，且该地址必须能被协议端访问（未配置时合并转发内视频失败并降级为仅发图文）
